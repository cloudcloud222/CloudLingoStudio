\# CloudLingo Studio 测试记录



这份文档记录当前版本做过的一些基础测试。测试目的不是覆盖所有边界情况，而是确认项目作为一个本地桌面翻译工具，核心流程可以跑通。



\## 1. 测试环境



本地测试环境：



```text

系统：Windows

语言：Python 3.10+

运行方式：源码运行

界面框架：CustomTkinter

启动命令：python app.py

```



依赖安装方式：



```bash

pip install -r requirements.txt

```



说明：由于项目需要调用外部大模型 API，部分测试需要用户自己配置可用的 API Key。



\## 2. 启动测试



测试内容：



\* 启动 `python app.py`；

\* 检查主窗口是否能正常打开；

\* 检查主界面控件是否正常显示；

\* 检查设置入口、术语库、Agent 配置、后台任务中心是否能打开。



测试结果：



```text

通过

```



备注：



主界面可以正常启动，窗口布局基本正常。中间控制区域在窗口高度较小时支持滚动，不会再出现底部按钮被遮挡的问题。

\## 5. 文档上传测试



测试内容：



\* 上传 txt 文件；

\* 上传 docx 文件；

\* 上传文本型 pdf 文件；

\* 检查文本是否能读取到输入区或进入文档翻译流程。



测试结果：



```text

基本通过

```



备注：



txt 和 docx 的读取比较稳定。文本型 pdf 可以读取正文内容，但复杂排版、扫描版 pdf、双栏论文、表格和公式暂时不能保证效果。

\## 13. 已知问题



当前版本仍然存在以下限制：



\* 没有完整自动化测试；

\* 没有 token 消耗统计；

\* 没有翻译质量评分；

\* 没有术语命中率检查；

\* PDF 复杂排版处理能力有限；

\* 扫描版 PDF 暂时不支持 OCR；

\* 多 Provider 兼容性还需要继续测试；

\* 本地配置文件需要用户自己注意隐私安全。

\## 15. 当前结论



当前版本已经可以作为个人桌面端 AI 翻译工具使用，核心流程包括 API 配置、文本翻译、文档上传、Agent Prompt、术语库、后台任务和结果导出。



项目还不是商业级产品，但作为个人学习、科研文档翻译和 AI 应用原型实践，已经具备基本可展示性。
